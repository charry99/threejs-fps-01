FROSTLINE is a three.js tactical FPS set at a midnight arctic relay station — Aurora vs Glacier, plant-the-charge, 5v5 with bots, first to 7 rounds, economy and buy menu, five weapons and three grenade types.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080. The game also runs from any static server serving `game/`.
